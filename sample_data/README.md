# Synthetic Sample Data

This directory contains synthetic incident records created exclusively for demonstrating the Analytics 2.0 workflow.

The dataset does not contain original enterprise, customer, account, employee, infrastructure, or incident information.

The sample records demonstrate fields used across the project, including:

- Incident description
- Configuration item
- Assignment group
- Level 1 category
- Level 2 category
- Capability
- Incident date

The data can be used to understand and test the public demonstration code included in this repository.

> All identifiers, descriptions, infrastructure names, assignment groups and classifications in this dataset are fictional.
