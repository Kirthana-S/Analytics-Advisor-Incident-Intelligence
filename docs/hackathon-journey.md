# Analytics 2.0 – Hackathon Journey

## Overview

Analytics 2.0 was originally developed as part of a global enterprise technology hackathon.

The project was developed by a **3-member team** and progressed successfully through three competitive stages, ultimately winning the final competition.

More importantly, the project continued beyond the hackathon and was subsequently implemented across **130+ enterprise accounts**.

---

# The Challenge

The project addressed a practical incident analytics problem.

Large volumes of incident records required significant manual effort for:

- Data preparation
- Incident categorization
- Applying classification logic
- Identifying repetitive issues
- Converting incident data into operational insights

Analytics 2.0 was developed to automate and standardize this process using:

```text
Python
+
Regular Expressions
+
Data Analytics
+
Power BI
+
Machine Learning
```

## Stage 1 – Regional

Analytics 2.0 first competed at the regional level.

The solution successfully progressed through this stage as a winning project.

## Stage 2 – Cross-Regional

Following the regional success, the project competed against successful teams from a broader set of regions.

Analytics 2.0 again progressed as a winning solution.

The final stage brought together top-performing teams from the different regions.

Analytics 2.0 successfully won the final stage of the hackathon.
